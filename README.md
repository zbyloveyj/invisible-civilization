# 看不见的文明

**微生物与人类的三百年**  
长篇科学历史小说 · 一心问道 著

本项目用于持续创作、修订与校勘《看不见的文明》。作品围绕1665—2026年间微生物学、医学、遗传学、生态学与现代生命科学的发展，以现代研究者程屿的经历贯穿六卷历史故事。

## 创作进度

- 全书结构：六卷、四十八章
- 当前阶段：完整文学第二稿，正在进行人物深化、科学史核验及文学精修
- 下一目标：逐章扩写与统一叙事节奏，完善科学史出处、术语与版权校勘
- **注意：本仓库目前为公开仓库，但尚未公开上传小说全文。**

## 写作原则

正文采用中文长篇小说自然段落，不将科学史写成连续的人物传记。真实历史与文学虚构在章末区分；微生物—疾病关联、预测模型与因果机制不混同。章节修改优先提升人物行动、场景和情节后果，而不是堆积科学名词。
