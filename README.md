## 在线阅读功能

网站采用文学出版式编辑设计，包括六卷扉页、带有48章故事简介和三条阅读路线的目录、全文目录筛选与搜索、上/下章切换、手机响应式布局、字体大小调整、日夜模式、书签、阅读进度、选中文本摘录与本地笔记。个人阅读数据仅保存于当前浏览器，不会同步或上传到 GitHub。

## 项目结构

- `_quarto.yml`：Quarto Book 配置
- `index.qmd`：作品首页
- `contents.qmd`：四十八章目录
- `volumes/`：六卷独立扉页
- `chapters/`：全部小说正文
- `styles/reader.css`：文学编辑视觉样式
- `styles/reader.html`：阅读交互与本地笔记
- `styles/chapter-reader.css`：独立小说阅读版心、字体和图版样式
- `styles/chapter-reader.html`：可展开的六卷目录抽屉
- `scripts/site_smoke_test.py`：发布前页面与脚本检查

修改小说后提交到 `main` 分支，将自动重新构建 GitHub Pages。

本地执行：

```bash
quarto render --to html
python scripts/site_smoke_test.py
```
