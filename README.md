## 使用方法

项目使用 [Quarto](https://quarto.org/docs/books/) 维护网站：


GitHub Pages 由 `.github/workflows/publish.yml` 构建部署；如尚未启用，请到仓库 Settings → Pages → Build and deployment，将 Source 设置为 **GitHub Actions**。
