## 项目结构

- `_quarto.yml`：Quarto Book 配置
- `index.qmd`：作品首页
- `contents.qmd`：四十八章目录
- `volumes/`：六卷独立扉页
- `chapters/`：全部小说正文
- `styles/reader.css`：文学编辑视觉样式
- `styles/reader.html`：阅读交互与本地笔记
- `scripts/site_smoke_test.py`：发布前页面与脚本检查

修改小说后提交到 `main` 分支，将自动重新构建 GitHub Pages。

本地执行：

```bash
quarto render --to html
python scripts/site_smoke_test.py
```

当前为持续修订的文学统稿；科学史书目与部分细节仍需最终审校。公开阅读不等于作品进入公共领域。
